# License and updates

**Settings → License & updates** is one section with two blocks: entitlement and application updates. **Update information** in the sidebar is the changelog.

## License

| Field | Meaning |
| --- | --- |
| Status | Active or inactive |
| License ID | Order id when active |
| Expiry | Date or remaining time |
| Device key | This PC’s binding id |
| Control panel | Opens the [online dashboard](https://rocketman-streams.com/#dashboard) to manage the license and bind this application |

An **active license** is required for automatic triggers (overlays, sounds, timer rules, hotkeys, game actions) and for **creating** a [cooperative sync](./user-coop-sync.md) room. Connecting platforms, watching [chat](./user-chat.md) and [events](./user-events.md), and **joining** a room work without a license.

## Application updates

| Control | What it does |
| --- | --- |
| **Check for updates** | Manual check (not used in unpackaged development builds) |
| **Update mode** | Manual / download automatically / install automatically |
| **Release channel** | `main`, `beta`, or `develop`. Protected channels unlock after the license validates. |
| **Download / Install now** | When a version is ready |
| Progress | Shown while a download runs |

On unsigned macOS builds, updates download automatically but you install the package yourself.

## Update information

After an app update, this section can open automatically with notes for versions you have not seen yet (up to the version you just installed). You can reopen it anytime from the sidebar.

With an active license you can rate each version from 1 to 10. The section shows the community average, how many ratings there are, and your score.
