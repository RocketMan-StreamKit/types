# Chat window

Open **Chat window** from the [main window](./user-main-window.md). It merges chat from connected streaming addons into one list, with badges, emotes, avatars, and optional colors where the platform provides them.

## Reading chat

- New messages pin you to the bottom. If you scroll up to read history, a counter of new messages appears; click it (or scroll down) to jump back.
- Scroll up to load older messages.
- System lines from the app or addons show a **System message** marker after the platform icon.
- Messages marked as mentions of you are highlighted.
- Right-click a nickname to insert `@{username}` into the composer.
- Right-click a message to delete it from this window (same idea as deleting a row in [Latest events](./user-events.md)).

Emotes that were recognized when the message arrived stay on that line even if you later remove the emote addon.

## Sending replies

If at least one streaming addon can send chat, a composer appears at the bottom. Press Enter to send.

When several send-capable addons are installed, a target selector on the left defaults to **All**. Pick one platform to send only there.

The composer is hidden when no addon exposes chat send.

## Links

With clickable links enabled, http(s) URLs in chat (and in latest events) open in your **external browser**. The first time a domain appears, StreamKit+ asks you to confirm; confirmed domains are remembered.

## Chat appearance

Open **Settings → Chat window** (or the gear in the chat footer) to change:

| Option | Effect |
| --- | --- |
| Clickable links | Detect URLs; warn on first visit to a domain |
| Avatars | Show platform avatars when available |
| Platform badges | Role / subscription badges next to the nickname |
| Font and size | Message typography |

Drafts preview live in the open chat window. If you cancel, leave the section, or close settings without saving, the preview reverts.
