# Таймер донату

Таймер — зворотний відлік (або відлік угору) для цілей стріму. **Живе керування** — на [головному вікні](./user-main-window.md). **Налаштування → Таймер донату** задають файли, формат, поведінку й автоматичні правила.

Автоматичні зміни часу за подіями потребують активної [ліцензії](./user-license.md). Ручні правки на головному вікні працюють завжди.

## Файли для OBS

Укажіть **папку даних таймера**. Туди пишуться файли (зокрема `timer.txt` і `timerSeconds.txt`) для текстового джерела OBS. Якщо папка порожня, файли йдуть у каталог даних застосунку.

**Формат відображення** — наприклад `HH:mm:ss` або `mm:ss`. Він же використовується в головному вікні та у файлах.

## Прапорці поведінки

| Параметр | Ефект |
| --- | --- |
| **Враховувати ручні зміни в доданому часі** | Правка часу, що залишився, на головному вікні оновлює лічильник «Додано» (за замовчуванням увімкнено). |
| **Показувати ручні зміни в останніх подіях** | Ручні правки з’являються в [Останніх подіях](./user-events.md) (за замовчуванням увімкнено). |
| **Зворотний режим таймера** | Рахує вгору, а не вниз. |
| **Лише під час стріму** | Пауза, поки жодна платформа не повідомляє про ефір (за замовчуванням увімкнено). |
| **Зворотні донати** | Збіглі донати й правила **віднімають** час замість додавання. |

**Ліміт** на головному вікні порівнюється з **доданим часом**, а не із залишком. Це стеля, скільки додаткового часу можуть накидати донати.

## Автоматичні правки

Правила додають (або віднімають) секунди за збігом події: аддон-джерело, тип події, опорна сума й валюта, скільки секунд. Суми донатів можуть масштабуватися пропорційно (наприклад +60 секунд за задану суму).

Модель тригерів та сама, що в [оверлеїв](./user-overlay.md): джерело **Усі** — усі донат-платформи в одній валюті.

## Спільні кімнати

Якщо ви в кімнаті зі спільною трансляцією таймера, в учасників з’являється папка `timer-{ROOM_ID}` всередині папки таймера. Див. [Спільна синхронізація](./user-coop-sync.md).
