# LLM Access

**Налаштування → LLM Access** зберігає **профілі** мовних моделей: Ollama на вашому ПК, Gemini, Groq, OpenAI, OpenRouter та інші сумісні з OpenAI провайдери.

Аддони з дозволом можуть надсилати запити через ці профілі. **Ключі API не залишають StreamKit+** і аддонам не видимі.

Розділ потрібен, лише якщо аддон (або вбудований тестовий чат) має звертатися до моделі.

## Глобальні параметри

| Параметр | Призначення |
| --- | --- |
| **Увімкнути LLM Access** | Вимкнено — аддони не можуть викликати модель. Тестовий чат на цій сторінці все одно працює. |
| **Профіль за замовчуванням** | **Авто** (найкращий доступний увімкнений профіль) або конкретний профіль |
| **Дозволити аддонам обирати профіль** | Вимкнено — аддони завжди йдуть через вибір за замовчуванням |
| **Лише безкоштовні** | Автомаршрутизація пропускає платні профілі й моделі |

Після правок цих опцій або профілів натисніть **Зберегти** на спільній панелі налаштувань.

## Профілі

Додавання, правка, видалення:

- Провайдер, модель, необов’язковий базовий URL, ключ API
- Креативність (temperature) і максимальна довжина відповіді
- Прапорці «увімкнений» / «платний»

**Оновити моделі** підтягує список моделей провайдера, якщо це підтримується. **Знайти Ollama** шукає локальне встановлення Ollama.

За ліміту запитів авто-режим може перемкнутися на інший увімкнений профіль.

## Тестовий чат

**Відкрити тестовий чат** на цій сторінці: діалог (кілька реплік) або один запит, із вибором профілю. Так перевіряють ключ і модель до ввімкнення аддона, якому потрібен LLM Access.
