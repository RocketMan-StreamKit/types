# Налаштування

Відкрийте Налаштування шестірнею на [головному вікні](./user-main-window.md). Бічна панель — усі модулі. Вікно пам’ятає останній відкритий розділ.

У більшості розділів унизу **Зберегти / Скинути**. Збереження застосовує зміни, скидання скасовує незбережені правки. У детальних екранів (оверлей, звук, пресет хоткея, аддон) своя панель збереження.

Частина пунктів потребує **перезапуску застосунку** (апаратне прискорення, продуктивна GPU, резервний API / проксі). Інтерфейс попереджає про це. Після збереження скористайтеся **Перезапуск застосунку** в заголовку.

У кожного розділу налаштувань можна знову запустити навчання з іконки в заголовку.

## Основні

Глобальні параметри всього застосунку.

| Параметр | Призначення |
| --- | --- |
| **Мова** | Меню, налаштування й сповіщення (англійська, російська, українська) |
| **Валюта** | Валюта відображення донатів і сум. Пошук за назвою або кодом. |
| **Апаратне прискорення** | GPU для інтерфейсу. Вимкніть, якщо гра вже навантажує відеокарту. Потрібен перезапуск. |
| **Продуктивна GPU** | На ноутбуках надає перевагу дискретній відеокарті. Видно лише за ввімкненого апаратного прискорення. Потрібен перезапуск. |
| **Статус Discord** | Rich Presence, поки запущено Discord |
| **Режим розробника** | Додаткова діагностика в упакованих збірках (у dev-збірках завжди ввімкнений) |
| **Резервний API-сервер** | Запасний хост API, якщо основний недоступний. Потрібен перезапуск. |
| **Відкрити папку логів** | Каталог логів у файловому менеджері |
| **Скинути позиції вікон** | Повернути стандартне розташування вікон |
| **Ярлик на Linux** | В упакованих збірках Linux можна зареєструвати StreamKit+ у меню KDE, GNOME та інших |

## Інтерфейс

**Налаштування → Інтерфейс** — колірні схеми.

- Вбудовані: система, світла, темна й іменовані пресети (наприклад Dark Moon, Cyberpunk, Matrix).
- **Власні схеми**: створити, застосувати, експортувати або імпортувати палітру рядком base64. У кожного пресета — кольори, типографіка й заокруглення.
- Попередній перегляд іде по відкритих вікнах **до** збереження. Скидання або вихід без збереження знімає попередній перегляд.

Експорт та імпорт зручні, щоб перенести тему на інший ПК. Якщо файл зроблено в іншій версії StreamKit+, застосунок може попросити підтвердження.
