# Озвучення тексту

**Налаштування → Озвучення тексту** читає повідомлення вголос. Аддони з дозволом можуть надсилати текст у вибраний тут рушій (наприклад алерти донатів). Ви обираєте рушій, голоси й гучність; ключі API та локальні моделі залишаються в StreamKit+.

## Загальні параметри

| Параметр | Призначення |
| --- | --- |
| **Увімкнути TTS** | Головний перемикач |
| **Рушій мовлення** | Piper (локально), ElevenLabs (хмара) або Windows TTS |
| **Гучність** | 0–200% (вище 100% підсилюється в головному вікні) |
| **Мова, тестова фраза, Перевірити голос** | Перевірка голосу до ефіру |

Якщо аддон не вказав мову, StreamKit+ сам визначає англійську, російську або українську (запасний варіант — англійська).

## Piper (за замовчуванням)

Локальні голоси [Piper](https://github.com/rhasspy/piper). Обліковий запис не потрібен.

- Завантаження й керування ONNX-моделями за мовами (англійська, російська, українська).
- Опційно **CUDA** на NVIDIA (Windows і Linux).
- **Режим запуску**: одразу або за першої фрази (економить RAM; перша репліка може бути повільнішою).
- Швидкість і виразність.
- Індикатор, чи запущений воркер.

Якщо воркер Piper відсутній у встановленні, розділ про це повідомляє.

## ElevenLabs

Хмарні голоси через API [ElevenLabs](https://elevenlabs.io/) (`eleven_multilingual_v2`).

- Один або кілька API-токенів із лімітом символів. StreamKit+ бере токен із найбільшим залишком квоти (кеш на кілька хвилин).
- Спільні налаштування голосу: стабільність, подібність, стиль, швидкість.
- Оновлення лімітів із панелі, коли потрібна актуальна квота.

Потрібні мережа й чинний токен.

## Windows TTS

Системні голоси (SAPI). **Лише Windows** — на Linux і macOS панель недоступна.

Голос, швидкість і гучність задаються окремо для кожної мови.
