Ліцензія (license)

Читання стану ліцензії застосунку з аддона-інтеграції. Додаткові дозволи не потрібні.

Вихідний ключ пристрою не передається. getInfo() повертає MD5-хеш у hex (keyMd5), щоб аддон міг ідентифікувати встановлення на зовнішніх сервісах без витоку ключа.

license.active

Синхронний прапорець у воркері інтеграції. Оновлюється при зміні валідності ліцензії в основному процесі (той самий поріг, що й для тригерів інтеграцій).

if (!license.active) {
  console.warn('Тригери інтеграцій вимкнено');
}

license.id

Синхронний ID ліцензії (номер замовлення з налаштувань → «ID ліцензії»). Порожній рядок, якщо ліцензія неактивна.

if (license.id) {
  console.log('ID ліцензії', license.id);
}

license.keyMd5

Синхронний MD5 hex-дайджест ключа пристрою (вихідний ключ не передається).

console.log('Відбиток ключа', license.keyMd5);

license.getInfo()

Повертає поточний знімок ліцензії:

Поле Тип Опис
valid boolean Чи активна ліцензія
expiresSeconds number Секунд до закінчення; -1 — безстроково; 0 — прострочена
licenseId string ID замовлення ліцензії (порожньо, якщо неактивна)
keyMd5 string MD5 hex-дайджест ключа пристрою 
const info = await license.getInfo();
if (info.success && info.valid) {
  console.log('Замовлення', info.licenseId);
  console.log('Відбиток ключа', info.keyMd5);
}
