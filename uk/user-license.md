# Ліцензія та оновлення

**Налаштування → Ліцензія та оновлення** — один розділ із двох блоків: ліцензія й оновлення застосунку. **Інформація про оновлення** в бічній панелі — список змін.

## Ліцензія

| Поле | Зміст |
| --- | --- |
| Статус | Активна чи ні |
| ID ліцензії | Номер замовлення за активної ліцензії |
| Термін | Дата або час, що залишився |
| Ключ пристрою | Прив’язка цього ПК |
| Панель керування | [Онлайн-кабінет](https://rocketman-streams.com/#dashboard) — керування ліцензією та прив’язка застосунку |

**Активна ліцензія** потрібна для автоматичних тригерів (оверлеї, звуки, правила таймера, хоткеї, ігрові дії) і для **створення** кімнати [спільної синхронізації](./user-coop-sync.md). Підключення платформ, [чат](./user-chat.md) і [події](./user-events.md), а також **вхід** до кімнати працюють без ліцензії.

## Оновлення застосунку

| Параметр | Призначення |
| --- | --- |
| **Перевірити оновлення** | Ручна перевірка (у непакованих dev-збірках не використовується) |
| **Режим оновлення** | Вручну / завантажувати автоматично / установлювати автоматично |
| **Канал релізів** | `main`, `beta` або `develop`. Захищені канали відкриваються після перевірки ліцензії. |
| **Завантажити / Установити зараз** | Коли версія готова |
| Прогрес | Поки йде завантаження |

На непідписаних збірках macOS оновлення завантажується само, пакет ви встановлюєте вручну.

## Інформація про оновлення

Після оновлення застосунку розділ може відкритися сам із нотатками за версіями, які ви ще не бачили (до щойно встановленої). Його завжди можна відкрити з бічної панелі.

З активною ліцензією кожну версію можна оцінити від 1 до 10. Показуються середнє спільноти, кількість оцінок і ваша оцінка.
