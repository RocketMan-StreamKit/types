Документація StreamKit+

Посібники для стримерів (як користуватися застосунком) і для розробників аддонів (API пісочниці, маніфест, дозволи).

Інтеграційні аддони розширюють StreamKit+ з ізольованого worker-процесу. Код аддона виконується у VM-пісочниці та використовує глобальні API (network, events, api, …) — імпорт SDK всередині worker недоступний.

Для стримерів

Як користуватися StreamKit+ як настільним застосунком — не як писати аддони.

API пісочниці

Розділ Опис
Огляд API Усі глобальні об'єкти
events Шина подій і прив'язка HTTP-обробників
network HTTP-клієнт, ендпоінти, WebSocket, SSE, SignalR, Socket.IO
api.config і storage Параметри, конфіг застосунку, файлове сховище
Доступ до файлів Читання/запис за схваленими користувачем шляхами (files API)
Озвучення тексту (tts) Озвучення через TTS-движок користувача (дозвіл TTS)
LLM Access (llm) Запити до нейромереж через профілі користувача (дозвіл LLM)
Завантаження yt-dlp (ytdlp) Завантаження медіа через вбудований yt-dlp (FILE_ACCESS + NETWORK_REQUEST)
addons (RPC) Запити та події між аддонами
dashboard Віджет подій, чат, тригери оверлею
status, notify, ui Рядок стану, онлайн глядачів, сповіщення, сторінки OAuth
Сповіщення (alerts) Координація показу сповіщень між аддонами (без дозволу)
Валюта Основна валюта користувача та конвертація сум
Визначення мови (language) Визначення мови тексту через fastText (~176 мов; без дозволу)
Утиліти Таймери, crypto, console, режим розробника

Типізація

Встановіть оголошення пісочниці з npm — версія пакета має збігатися з цільовою версією StreamKit+:

npm install --save-dev @rocketman-streamkit/types

Див. Налаштування TypeScript — tsconfig.json і глобали (declare global, без імпортів у коді аддона).
