Настройки

Откройте Настройки шестерёнкой на главном окне. Боковая панель — все модули. Окно помнит последний открытый раздел.

У большинства разделов внизу Сохранить / Сбросить. Сохранение применяет изменения, сброс отменяет несохранённые правки. У детальных экранов (оверлей, звук, пресет хоткея, аддон) своя панель сохранения.

Часть пунктов требует перезапуска приложения (аппаратное ускорение, производительная GPU, резервный API / прокси). Интерфейс предупреждает об этом. После сохранения используйте Перезапуск приложения в заголовке.

У каждого раздела настроек можно заново запустить обучение с иконки в заголовке.

Интерфейс

Настройки → Интерфейс — цветовые схемы.

  • Встроенные: система, светлая, тёмная и именованные пресеты (например Dark Moon, Cyberpunk, Matrix).
  • Свои схемы: создать, применить, экспортировать или импортировать палитру строкой base64. У каждого пресета — цвета, типографика и скругление.
  • Предпросмотр идёт по открытым окнам до сохранения. Сброс или уход без сохранения снимает предпросмотр.

Экспорт и импорт удобны, чтобы перенести тему на другой ПК. Если файл сделан в другой версии StreamKit+, приложение может попросить подтверждение.
