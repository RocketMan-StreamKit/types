Озвучка текста

Настройки → Озвучка текста читает сообщения вслух. Аддоны с разрешением могут отправлять текст в выбранный здесь движок (например алерты донатов). Вы выбираете движок, голоса и громкость; ключи API и локальные модели остаются в StreamKit+.

Общие параметры

Параметр Назначение
Включить TTS Главный переключатель
Движок речи Piper (локально), ElevenLabs (облако) или Windows TTS
Громкость 0–200% (выше 100% усиливается в главном окне)
Язык, тестовая фраза, Проверить голос Проверка голоса до эфира

Если аддон не указал язык, StreamKit+ сам определяет английский, русский или украинский (запасной вариант — английский).

Piper (по умолчанию)

Локальные голоса Piper. Аккаунт не нужен.

  • Скачивание и управление ONNX-моделями по языкам (английский, русский, украинский).
  • Опционально CUDA на NVIDIA (Windows и Linux).
  • Режим запуска: сразу или при первой фразе (экономит RAM; первая реплика может быть медленнее).
  • Скорость и выразительность.
  • Индикатор, запущен ли воркер.

Если воркер Piper отсутствует в установке, раздел об этом сообщает.

ElevenLabs

Облачные голоса через API ElevenLabs (eleven_multilingual_v2).

  • Один или несколько API-токенов с лимитом символов. StreamKit+ берёт токен с наибольшим остатком квоты (кэш на несколько минут).
  • Общие настройки голоса: стабильность, сходство, стиль, скорость.
  • Обновление лимитов с панели, когда нужна актуальная квота.

Нужны сеть и действующий токен.

Windows TTS

Системные голоса (SAPI). Только Windows — на Linux и macOS панель недоступна.

Голос, скорость и громкость задаются отдельно для каждого языка.
