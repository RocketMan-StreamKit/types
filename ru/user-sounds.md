# Звуковые эффекты

**Настройки → Звуковые эффекты** — список ваших звуков оповещения. Они играют, когда событие дашборда совпадает с триггерами — отдельно от [оверлеев](./user-overlay.md).

Автовоспроизведение требует активной [лицензии](./user-license.md).

## Список

- Создайте звук и откройте его для правки.
- Выключите звук, чтобы **не удалять** правила триггеров.
- Предпрослушивание из списка.

## Редактор

| Поле | Назначение |
| --- | --- |
| Имя | Подпись в интерфейсе и в [Последних событиях](./user-events.md) |
| Файл или URL | Локальный аудиофайл или ссылка |
| Громкость | 0–100 |
| Триггеры | Та же модель событий, что у оверлеев (источник, тип, сумма / награда / …) |
| Включён | Главный переключатель |

Сохраняйте с панели внизу карточки.

## Типовое использование

1. Один звук на новых фолловеров, другой — на донаты выше порога.
2. Сохраните и проверьте тестовым или реальным событием.
3. На строке события будет чип звука, если нужно повторить.

[Совместная синхронизация](./user-coop-sync.md) **не** передаёт звуки на другие ПК — только оверлей и хоткеи.
