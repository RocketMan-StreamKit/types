# Последние события

Откройте **Последние события** с [главного окна](./user-main-window.md). Это живая лента всего, что записало StreamKit+: донаты, фолловы, подписки, рейды, баллы канала, пользовательские события, ручные правки таймера, совместная синхронизация и другое.

Новые записи сверху. Прокрутка вниз подгружает старые. Кнопка **Наверх** возвращает к самым новым.

## Что в строке

- Иконка платформы и типа события
- Ник, сумма (в [валюте отображения](./user-settings.md)) и сообщение, если они есть
- Время
- Необязательные **чипы действий** для эффектов, которые сработали на это событие

Ссылки http(s) в тексте кликабельны, если это включено в настройках [окна чата](./user-chat.md). При первом открытии нового домена приложение просит подтверждение.

## Чипы действий

| Чип | Действие |
| --- | --- |
| Оверлей | Проиграть эффект снова или пропустить текущий |
| Звук | Повторить звук |
| Таймер | Сколько времени добавлено или вычтено |
| Хоткей | Какой пресет сработал |
| Совместная синхронизация | Синхронизированный эффект из комнаты |
| Аддон | Воспроизвести или остановить медиа, прикреплённое аддоном |

Так можно догнать пропущенный оверлей или проверить, что триггер настроен.

## Удаление записи

ПКМ по строке → удалить. Удаляется только локальная запись ленты: донат не отменяется и сообщение в чате платформы не исчезает.

## Пустая лента

Если ничего нет, стриминговый или донат-[аддон](./user-addons.md) не установлен, выключен или без входа. Смотрите строку статуса на главном окне, затем настройки аддона.
