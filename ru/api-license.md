# Лицензия (`license`)

Чтение состояния лицензии приложения из аддона-интеграции. Дополнительные разрешения не требуются.

Исходный ключ устройства **не передаётся**. `getInfo()` возвращает MD5-хеш в hex (`keyMd5`), чтобы аддон мог идентифицировать установку на внешних сервисах без утечки ключа.

## `license.active`

Синхронный флаг в воркере интеграции. Обновляется при смене валидности лицензии в основном процессе (тот же порог, что и для триггеров интеграций).

```js
if (!license.active) {
  console.warn('Триггеры интеграций отключены');
}
```

## `license.id`

Синхронный **ID лицензии** (номер заказа из настроек → «ID лицензии»). Пустая строка, если лицензия неактивна.

```js
if (license.id) {
  console.log('ID лицензии', license.id);
}
```

## `license.keyMd5`

Синхронный MD5 hex-дайджест ключа устройства (исходный ключ не передаётся).

```js
console.log('Отпечаток ключа', license.keyMd5);
```

## `license.getInfo()`

Возвращает текущий снимок лицензии:

| Поле | Тип | Описание |
| --- | --- | --- |
| `valid` | `boolean` | Активна ли лицензия |
| `expiresSeconds` | `number` | Оставшиеся секунды; `-1` — бессрочно; `0` — истекла |
| `licenseId` | `string` | ID заказа лицензии (пусто, если неактивна) |
| `keyMd5` | `string` | MD5 hex-дайджест ключа устройства |

```js
const info = await license.getInfo();
if (info.success && info.valid) {
  console.log('Заказ', info.licenseId);
  console.log('Отпечаток ключа', info.keyMd5);
}
```
