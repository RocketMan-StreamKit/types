Документация StreamKit+

Руководства для стримеров (как пользоваться приложением) и для разработчиков аддонов (API песочницы, манифест, разрешения).

Интеграционные аддоны расширяют StreamKit+ из изолированного worker-процесса. Код аддона выполняется в VM-песочнице и использует глобальные API (network, events, api, …) — импорт SDK внутри worker недоступен.

API песочницы

Раздел Описание
Обзор API Все глобальные объекты
events Шина событий и привязка HTTP-обработчиков
network HTTP-клиент, эндпоинты, WebSocket, SSE, SignalR, Socket.IO
api.config и storage Параметры, конфиг приложения, файловое хранилище
Доступ к файлам Чтение/запись по одобренным пользователем путям (files API)
Озвучка текста (tts) Озвучка через TTS-движок пользователя (разрешение TTS)
LLM Access (llm) Запросы к нейросетям через профили пользователя (разрешение LLM)
Загрузки yt-dlp (ytdlp) Загрузка медиа через встроенный yt-dlp (FILE_ACCESS + NETWORK_REQUEST)
addons (RPC) Запросы и события между аддонами
dashboard Виджет событий, чат, триггеры оверлея
status, notify, ui Строка состояния, онлайн зрителей, уведомления, страницы OAuth
Оповещения (alerts) Координация показа оповещений между аддонами (без разрешения)
Валюта Основная валюта пользователя и конвертация сумм
Определение языка (language) Определение языка текста через fastText (~176 языков; без разрешения)
Утилиты Таймеры, crypto, console, режим разработчика

Типизация

Установите объявления песочницы из npm — версия пакета должна совпадать с целевой версией StreamKit+:

npm install --save-dev @rocketman-streamkit/types

См. Настройка TypeScript — tsconfig.json и глобалы (declare global, без импортов в коде аддона).
