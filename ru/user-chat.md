# Окно чата

Откройте **Окно чата** с [главного окна](./user-main-window.md). Чат с подключённых стриминговых аддонов собирается в один список: бейджи, эмоуты, аватары и цвета, если платформа их отдаёт.

## Чтение

- Новые сообщения удерживают вас внизу. Если прокрутили историю вверх, появляется счётчик новых; клик (или прокрутка вниз) возвращает к актуальному.
- Прокрутка вверх подгружает старые сообщения.
- Системные строки приложения или аддонов помечаются как **Системное сообщение** после иконки платформы.
- Упоминания вас подсвечиваются.
- ПКМ по нику вставляет `@{username}` в поле ввода.
- ПКМ по сообщению удаляет его из этого окна (как удаление строки в [Последних событиях](./user-events.md)).

Эмоуты, распознанные в момент получения, остаются на строке даже если потом удалить аддон эмоутов.

## Ответы

Если хотя бы один стриминговый аддон умеет отправлять чат, внизу появляется поле. Enter — отправить.

Если таких аддонов несколько, слева селектор цели: по умолчанию **Все**. Можно выбрать одну платформу.

Поле скрыто, если ни один аддон не умеет отправлять чат.

## Ссылки

При включённых кликабельных ссылках URL в чате (и в последних событиях) открываются во **внешнем браузере**. Первый визит на домен — подтверждение; подтверждённые домены запоминаются.

## Внешний вид чата

**Настройки → Окно чата** (или шестерёнка в подвале чата):

| Параметр | Эффект |
| --- | --- |
| Кликабельные ссылки | Распознавать URL; предупреждение при первом визите на домен |
| Аватары | Показывать аватары платформы |
| Бейджи платформы | Роль / подписка рядом с ником |
| Шрифт и размер | Типографика сообщений |

Черновики сразу видны в открытом окне чата. Отмена, уход из раздела или закрытие настроек без сохранения откатывает предпросмотр.
