Лицензия и обновления

Настройки → Лицензия и обновления — один раздел из двух блоков: лицензия и обновления приложения. Информация об обновлении в боковой панели — список изменений.

Лицензия

Поле Смысл
Статус Активна или нет
ID лицензии Номер заказа при активной лицензии
Срок Дата или оставшееся время
Ключ устройства Привязка этого ПК
Панель управления Онлайн-кабинет — управление лицензией и привязка приложения

Активная лицензия нужна для автоматических триггеров (оверлеи, звуки, правила таймера, хоткеи, игровые действия) и для создания комнаты совместной синхронизации. Подключение платформ, чат и события, а также вход в комнату работают без лицензии.

Обновления приложения

Параметр Назначение
Проверить обновления Ручная проверка (в неупакованных dev-сборках не используется)
Режим обновления Вручную / скачивать автоматически / устанавливать автоматически
Канал релизов main, beta или develop. Защищённые каналы открываются после проверки лицензии.
Скачать / Установить сейчас Когда версия готова
Прогресс Пока идёт загрузка

На неподписанных сборках macOS обновление скачивается само, пакет вы устанавливаете вручную.

Информация об обновлении

После обновления приложения раздел может открыться сам с заметками по версиям, которые вы ещё не видели (до только что установленной). Его всегда можно открыть из боковой панели.

С активной лицензией каждую версию можно оценить от 1 до 10. Показываются среднее сообщества, число оценок и ваша оценка.
