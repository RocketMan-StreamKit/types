Интеграции хоткеев

Настройки → Интеграции хоткеев запускают клавиатурные сценарии по событию дашборда: паузы, блокировка клавиш, имитация нажатий, тапы и ввод текста.

Типичные задачи: переключить сцену OBS горячей клавишей, которую нажимает приложение, отправить ввод в игру или напечатать команду — при желании только когда выбранная программа на переднем плане.

Автозапуск требует активной лицензии. Античит может посчитать имитацию ввода подозрительной — используйте только там, где внешний ввод разрешён.

Клавиатурный агент

StreamKit+ сам клавиши не вставляет. Должен работать небольшой клавиатурный агент.

  • Старт и стоп — в этом разделе настроек.
  • Автозапуск поднимает агента вместе с приложением.
  • В Windows Запуск от администратора по умолчанию включён (нужен для части игр с повышением прав).
  • Статус должен быть «подключён / готов», иначе пресеты не сработают.
  • На Linux определение активного окна ожидает сессию X11. На macOS система безопасности может полностью заблокировать агента.

Агент останавливается при выходе из StreamKit+.

Пресеты

У каждого пресета:

  • Триггеры (как у оверлеев)
  • Необязательная привязка к процессу: всегда, только если exe на переднем плане, или пока процесс запущен
  • Сценарий: упорядоченный список пауза / блокировка клавиши / разблокировка / вниз / вверх / тап / ввод текста (US QWERTY)

Проверить текущие настройки запускает сценарий после короткой задержки (по умолчанию 5 секунд), чтобы успеть переключиться в нужное окно.

Папки

Группируйте пресеты по папкам. Правила автоназначения — подстрока в имени пресета или exe целевого процесса. Папку (все пресеты и правила) можно экспортировать или импортировать одной строкой base64 — удобно перенести набор на другой ПК.

Совместная синхронизация

В комнате пресеты хоткеев могут выполняться и у участников. У каждого должен быть запущен свой клавиатурный агент. Звуки и игровые триггеры не синхронизируются.
