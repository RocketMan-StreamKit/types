# Аддоны и каталог

StreamKit+ не «зашивает» Twitch, DonationAlerts или конкретный оверлей. Это **аддоны**, которые вы ставите сами. Здесь — каталог и **платформенные** аддоны (стриминг и донаты). Остальные типы: [оверлей](./user-overlay.md), [виджеты и приложения](./user-widgets.md), [игры](./user-games.md).

## Каталог аддонов

**Настройки → Каталог аддонов** — рекомендованные аддоны из онлайн-каталога.

- Фильтр по категории и поиск по имени.
- Счётчики загрузок и звёздный рейтинг (оценки — при активной [лицензии](./user-license.md)).
- **Установить** скачивает аддон и показывает **разрешения**.
- **Установить по ID** — id каталога или URL репозитория GitHub.
- Полный каталог также на [rocketman-streams.com](https://rocketman-streams.com/#addons).
- Папку уже установленного аддона можно открыть из списка каталога.

Установка из локальной папки или zip (включая перетаскивание на окно) ограничена **10 МБ**. Если аддону нужны другие аддоны, диалог подтверждения может поставить их сначала.

Если приложение старше требуемой версии аддона, установка и обновление блокируются, пока не обновите StreamKit+.

## Стриминг и донаты

**Настройки → Интеграции** делятся на:

- **Стриминговые платформы** — чат, фолловы, подписки, биты, рейды, баллы канала и похожие события
- **Донат-платформы** — чаевые сервисов вроде DonationAlerts или DonatePay

Обычный порядок:

1. Установить из каталога.
2. Открыть аддон, ввести токены или войти, **Сохранить**.
3. **Включить** аддон.
4. Проверить подключение в строке статуса [главного окна](./user-main-window.md).

Наведите на заблокированный переключатель включения — увидите причину (нет обязательных аддонов, они выключены или аддон забанен в каталоге).

## Повседневная работа

- Включайте и выключайте без удаления. Удаление **сохраняет** настройки аддона: при повторной установке токены и предпочтения вернутся.
- Проверяйте обновления каталога в настройках и обновляйте аддон при новой версии.
- Одноразовое уведомление, когда в каталоге появляется **новый** аддон.
- Забаненные аддоны каталога отключаются сами и снова включить их нельзя.
- У работающих аддонов под именем могут быть CPU и RAM. PID виден только в режиме разработчика.
- Если аддон падает по кругу, автоперезапуск останавливается, пока вы не запустите его снова из настроек.

## Какие разрешения бывают

Их подтверждают при установке. Часто встречаются:

| Разрешение (простыми словами) | Смысл |
| --- | --- |
| Сеть | Аддон может обращаться к сайтам и API |
| События дашборда | Может публиковать события и регистрировать типы триггеров |
| Доступ к файлам | Чтение и запись только в одобренных вами папках (плюс автоматическая временная папка) |
| Озвучка | Может говорить через ваш движок [TTS](./user-tts.md) |
| LLM | Может слать запросы через ваши профили [LLM](./user-llm.md) (ключи остаются в StreamKit+) |
| Отправка в чат | Может отправлять сообщения через аддоны, умеющие писать в чат |

Выданные пути к файлам можно отозвать позже в настройках этого аддона.
