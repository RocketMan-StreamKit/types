# LLM Access

**Настройки → LLM Access** хранит **профили** языковых моделей: Ollama на вашем ПК, Gemini, Groq, OpenAI, OpenRouter и другие совместимые с OpenAI провайдеры.

Аддоны с разрешением могут слать запросы через эти профили. **Ключи API не покидают StreamKit+** и аддонам не видны.

Раздел нужен, только если аддон (или встроенный тестовый чат) должен обращаться к модели.

## Глобальные параметры

| Параметр | Назначение |
| --- | --- |
| **Включить LLM Access** | Выключено — аддоны не могут вызывать модель. Тестовый чат на этой странице всё равно работает. |
| **Профиль по умолчанию** | **Авто** (лучший доступный включённый профиль) или конкретный профиль |
| **Разрешить аддонам выбирать профиль** | Выключено — аддоны всегда идут через выбор по умолчанию |
| **Только бесплатные** | Автомаршрутизация пропускает платные профили и модели |

После правок этих опций или профилей нажмите **Сохранить** на общей панели настроек.

## Профили

Добавление, правка, удаление:

- Провайдер, модель, необязательный базовый URL, ключ API
- Креативность (temperature) и максимальная длина ответа
- Флаги «включён» / «платный»

**Обновить модели** подтягивает список моделей провайдера, если это поддерживается. **Найти Ollama** ищет локальную установку Ollama.

При лимите запросов авто-режим может переключиться на другой включённый профиль.

## Тестовый чат

**Открыть тестовый чат** на этой странице: диалог (несколько реплик) или один запрос, с выбором профиля. Так проверяют ключ и модель до включения аддона, которому нужен LLM Access.
