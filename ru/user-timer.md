# Таймер доната

Таймер — обратный отсчёт (или отсчёт вверх) для целей стрима. **Живое управление** — на [главном окне](./user-main-window.md). **Настройки → Таймер доната** задают файлы, формат, поведение и автоматические правила.

Автоматические изменения времени по событиям требуют активной [лицензии](./user-license.md). Ручные правки на главном окне работают всегда.

## Файлы для OBS

Укажите **папку данных таймера**. Туда пишутся файлы (в том числе `timer.txt` и `timerSeconds.txt`) для текстового источника OBS. Если папка пустая, файлы идут в каталог данных приложения.

**Формат отображения** — например `HH:mm:ss` или `mm:ss`. Он же используется в главном окне и в файлах.

## Флаги поведения

| Параметр | Эффект |
| --- | --- |
| **Учитывать ручные изменения в добавленном времени** | Правка оставшегося времени на главном окне обновляет счётчик «Добавлено» (по умолчанию включено). |
| **Показывать ручные изменения в последних событиях** | Ручные правки появляются в [Последних событиях](./user-events.md) (по умолчанию включено). |
| **Обратный режим таймера** | Считает вверх, а не вниз. |
| **Только во время стрима** | Пауза, пока ни одна платформа не сообщает об эфире (по умолчанию включено). |
| **Обратные донаты** | Совпавшие донаты и правила **вычитают** время вместо добавления. |

**Лимит** на главном окне сравнивается с **добавленным временем**, а не с оставшимся. Это потолок, сколько дополнительного времени могут накидать донаты.

## Автоматические правки

Правила добавляют (или вычитают) секунды при совпадении события: аддон-источник, тип события, опорная сумма и валюта, сколько секунд. Суммы донатов могут масштабироваться пропорционально (например +60 секунд за заданную сумму).

Модель триггеров та же, что у [оверлеев](./user-overlay.md): источник **Все** — все донат-платформы в одной валюте.

## Совместные комнаты

Если вы в комнате с общей трансляцией таймера, у участников появляется папка `timer-{ROOM_ID}` внутри папки таймера. См. [Совместная синхронизация](./user-coop-sync.md).
