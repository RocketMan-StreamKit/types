# Настройки

Откройте Настройки шестерёнкой на [главном окне](./user-main-window.md). Боковая панель — все модули. Окно помнит последний открытый раздел.

У большинства разделов внизу **Сохранить / Сбросить**. Сохранение применяет изменения, сброс отменяет несохранённые правки. У детальных экранов (оверлей, звук, пресет хоткея, аддон) своя панель сохранения.

Часть пунктов требует **перезапуска приложения** (аппаратное ускорение, производительная GPU, резервный API / прокси). Интерфейс предупреждает об этом. После сохранения используйте **Перезапуск приложения** в заголовке.

У каждого раздела настроек можно заново запустить обучение с иконки в заголовке.

## Основные

Глобальные параметры всего приложения.

| Параметр | Назначение |
| --- | --- |
| **Язык** | Меню, настройки и уведомления (английский, русский, украинский) |
| **Валюта** | Валюта отображения донатов и сумм. Поиск по названию или коду. |
| **Аппаратное ускорение** | GPU для интерфейса. Выключите, если игра уже нагружает видеокарту. Нужен перезапуск. |
| **Производительная GPU** | На ноутбуках предпочитает дискретную видеокарту. Видно только при включённом аппаратном ускорении. Нужен перезапуск. |
| **Статус Discord** | Rich Presence, пока запущен Discord |
| **Режим разработчика** | Дополнительная диагностика в упакованных сборках (в dev-сборках всегда включён) |
| **Резервный API-сервер** | Запасной хост API, если основной недоступен. Нужен перезапуск. |
| **Открыть папку логов** | Каталог логов в файловом менеджере |
| **Сбросить позиции окон** | Вернуть стандартную раскладку окон |
| **Ярлык на Linux** | В упакованных сборках Linux можно зарегистрировать StreamKit+ в меню KDE, GNOME и других |

## Интерфейс

**Настройки → Интерфейс** — цветовые схемы.

- Встроенные: система, светлая, тёмная и именованные пресеты (например Dark Moon, Cyberpunk, Matrix).
- **Свои схемы**: создать, применить, экспортировать или импортировать палитру строкой base64. У каждого пресета — цвета, типографика и скругление.
- Предпросмотр идёт по открытым окнам **до** сохранения. Сброс или уход без сохранения снимает предпросмотр.

Экспорт и импорт удобны, чтобы перенести тему на другой ПК. Если файл сделан в другой версии StreamKit+, приложение может попросить подтверждение.
